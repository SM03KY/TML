Daily work log

Daily total is calculated from the two work sessions. Leave both time fields blank (shown as --:--), or set both to 00:00, for a session you did not work. Enter a complete time-in/time-out pair for each session you worked. Lunch/break time between morning and afternoon is not counted.

Import existing work logs

Paste one log per line; hyphen bullets are supported. Use [--:-- - --:--], [00:00:00 - 00:00:00], or [ - ] for a session with no time. A full-day leave/excuse with both sessions blank is also saved; add a note after the date, e.g. YYYY-MM-DD (Excuse leave):, to record the reason. You can paste multiple lines. Totals after the equals sign are references only; time is recalculated from the entries.
